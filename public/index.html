LearnON 网关正在运行 🦀

Rust 从零实现的 Nginx/OpenResty 风格网关：反代 + 负载均衡 + 健康检查 + rewrite + Lua/Rust 脚本层 + 共享字典。

路由功能
GET /hellocontent_by_lua 内联脚本
GET /api/timerewrite_by_lua_file + content_by_lua_file + ngx.sleep 异步
GET /api/protectedaccess_by_lua 鉴权（header: x-token: secret123）
GET /proxy/*proxy_pass 反代 + upstream 负载均衡 + 被动健康检查
GET /countngx.shared.DICT 共享字典原子计数（跨请求）
GET /gongx.redirect 302 外部重定向
GET /innerngx.exec 内部重定向（客户端无感跳到 /hello）
GET /api/toolsngx.re 正则 / escape_uri 编解码 / 请求体读取
GET /old/thingrewrite last -> /new/thing
